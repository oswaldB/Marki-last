# ST-021 : Visualiser le calendrier des relances
**Date** : 2026-01-18
**UI** : Intégration des logos et couleurs Marki.

---

## 🎯 Contexte
Permettre aux utilisateurs (PM/Dev) de visualiser les emails (envoyés/à envoyer) dans un calendrier interactif avec des filtres.

## 📜 Règles Métier
- **Visualisation du calendrier** : Les utilisateurs doivent pouvoir visualiser les emails dans un calendrier interactif.
- **Filtres** : Les utilisateurs doivent pouvoir appliquer des filtres pour afficher les emails envoyés ou à envoyer.

## 📝 Exigences Techniques
- **Interface utilisateur** : Création d'une interface pour le calendrier des relances.
- **Calendrier interactif** : Implémentation d'un calendrier interactif pour visualiser les emails.
- **Filtres** : Implémentation de filtres pour afficher les emails envoyés ou à envoyer.

## 📋 Flux Principal
1. Accéder à l'interface du calendrier des relances.
2. Appliquer des filtres pour afficher les emails envoyés ou à envoyer.
3. Visualiser les emails dans le calendrier interactif.
